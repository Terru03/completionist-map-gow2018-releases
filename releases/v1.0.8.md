## Install/update

Close game. Extract `CompletionistMap-v1.0.8.zip` fully, keep existing
`completionist_backup`, then run `Install.bat`.

Steam Deck/Linux:

```sh
bash Install-SteamDeck.sh "/path/to/GodOfWar"
```

Steam Launch Options:

```text
WINEDLLOVERRIDES="dxgi,version=n,b" %command%
```

Full manual/mod-manager steps in bundled `README.txt`.
