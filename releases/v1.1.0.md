# Completionist Map v1.1.0

2026-10-30. Nearby markers, a bigger compass, corrected positions and a safer install/uninstall.

## New

- **Nearby markers:** the nearest uncollected collectible of each family gets its compass marker and in-world icon, all families at once. `[Up Arrow]` on the world map cycles the range: 50 m (start), 100 m, Off, 25 m. Within 25 m the others show the game's white hint dot. A killed Raven or opened Nornir chest drops its marker at once.
- **Compass:** up to 10 side markers instead of 6, every marker on the bar with its distance, and one place always kept free for a marker you track. A tracked favour no longer drops off the compass after a checkpoint load.
- **One in-world icon per family** instead of the game's one in total.
- **36 corrected positions:** collectibles that sat up to 186 m off their real spot (the beach maze artefact, cipher chest and dig site, the Nornir puzzles in Tyr's Vault and others) now have their pin, compass marker and icon on the item.
- **Map:** opened chests and other collected items update the map at once; Odin's Raven pins follow the map filter; the `[Down Arrow]` Hide/Show prompt updates on every press; tracked markers show their in-world icon from 100 m (adjustable per family in `mods/completionist-map/settings.json`).

## Install, uninstall and logs (Windows)

- Extract the ZIP to its own folder **outside** the game folder and run `Install.bat` from there; it refuses to run from inside the game folder.
- Backups hold only the game's own files. Game files already replaced by an earlier install without a backup are named, with Steam's Verify integrity of game files as the way back.
- `Uninstall.bat` from any v1.1.0 or later package uninstalls, reading what was installed from `completionist_backup`, and removes every Completionist file, including leftovers from earlier versions.
- The main log `mods/loader_log.txt` is on by default for problem reports (`FileLogLevel = "off"` in `mods/loader_config.toml` turns it off and later installs keep that). The native log rotates at 4 MB.
- The README in the ZIP explains every feature, the logs and how to report a problem. Discord: https://discord.gg/URDc8uZmB

## Game version

The compass and in-world icon changes run on game version 1.0.13 (GoW.exe 1.0.475.7534) from any store, DRM-free copies included: `dxgi.dll` checks the game code and data it uses byte for byte before changing anything. Other game versions keep the game's own behaviour; everything else in the mod works on them.
