# Completionist Map v1.0.0

First public release for God of War (2018) PC.

- Collectible map pins and compass targets with custom art.
- Live compass distance and map show/hide toggle.
- Completion-aware marker tracking.
- Installer, uninstaller, and stock-file backups.

Download **CompletionistMap-v1.0.0.zip** from assets below. Screenshots included as separate assets. Current stable release is v1.0.1.
