# Completionist Map v1.1.1

2026-11-09. MY LIST, up to 5 tracked markers, the realm tear fix, and settings that are remembered between sessions.

## New

- **Realm tears:** an opened tear drops off the map, and only that tear. In v1.1.0 every tear left the map once a Realm Tear Labor tier was completed, even tears not yet opened, and some opened tears stayed. The mod now reads each tear's opened state from the save (read only, as before). Fixes [issue 1](https://github.com/Terru03/completionist-map-gow2018-releases/issues/1).
- **MY LIST:** a map filter page that shows only the kinds of marker you pick: any of the mod's families, and the game's own shops, mystic gateways, boat docks, area entrances, fight locations, Valkyries, quests and other locations. On MY LIST, `[Down Arrow]` opens an ON/OFF list; the filter name shows how many kinds are on. While the map was left on MY LIST, nearby markers follow it.
- **Track up to 5 markers:** with a marker tracked, hover another one: `[Triangle]` Add to Compass 2/5 keeps the others, `[Cross]` Replace in Compass swaps out only the marker you set with `[Cross]`, and `[Cross]` on a tracked marker removes only that one. `[Triangle]` Clear Compass (no marker under the cursor, or at 5/5) removes them all; a tracked favour stays. The mod's markers and the game's own can be mixed, with at most 2 of one kind on the compass at once (the game has only 2 compass icons per kind). Tracked markers come back after a load or restart, and a collected one drops off by itself.
- **Remembered between sessions:** MY LIST, the page the map was left on, the `[Up Arrow]` nearby range and the tracked markers, in `mods/completionist-map/map-preferences.txt`.
- **Nearby and tracking:** while anything is tracked, nearby markers are drawn in the world only, off the compass bar, and a tracked family gets no nearby marker.
- **Raven pins:** `[Cross]` and the map prompt now always act on the marker under the cursor. Before, a Raven hovered earlier could stay selected, so `[Cross]` on another marker tracked or removed that Raven and the prompt kept its text.

Buttons are named as on a PlayStation controller: `[Cross]` is A on Xbox and `[Enter]` / `[E]` on the keyboard; `[Triangle]` is Y on Xbox and the key the map footer shows.

## Install or update (Windows)

Extract the ZIP to its own folder **outside** the game folder and run `Install.bat` from there. It upgrades a v1.1.0 install in place; keep `completionist_backup` in the game folder. `Uninstall.bat` from any v1.1.0 or later package uninstalls, and this one also removes `map-preferences.txt`.

## Files

The map script, the Raven bridge DLL (`collectible-base-dxgi.dll`, now also reading realm tears and keeping `map-preferences.txt`) and `dxgi.dll` (which checks that DLL's hash) changed. Art, map data, the bundled Script Loader and the installer's safeguards are as in v1.1.0. The compass and in-world icon changes still need game version 1.0.13 (GoW.exe 1.0.475.7534) from any store.
