# Completionist Map v1.0.5 - Universal Compatibility & Chest Tracking

- **Universal Game Compatibility:** Supports all God of War (2018) PC releases, including Steam, Epic Games, GOG, and non-official builds (CODEX, repacks, etc.).
- **Dynamic Executable Detection:** Removed hardcoded game version locks from both the native bridge runtime (`dxgi.dll`) and the installer (`Install.bat` / `install.ps1`). Executable checks are non-blocking.
- **Chest Tracking Fix Retained:** Incorporates the player-verified v1.0.4 chest tracking fix in `mapmenu.lua` (SHA256: `89312da4a21d22bd651fe30ead5d45abddee6b318781fa9bd965315ada349787`), verifying inner owner ancestry so opened wooden and red/coffin chests disappear correctly.

- **Stability:** Retains Windows 10/11 compatibility layer protections to avoid early ntdll crashes.

## Native map filters

All custom markers are organized into dedicated collectible-category filters integrated with the game's native map filters. Use the normal map filter controls to focus on the marker types you want to see, such as Ravens, chests or Artefacts. Related Nornir puzzle markers are grouped under the Nornir Puzzle filter.
