# Completionist Map v1.0.1

Current stable release. Startup compatibility hotfix for God of War (2018) PC.

- Fixes startup when Windows DXGI exports differ or optional exports missing.
- Keeps graphics fallback when native checks fail. Full mod still needs supported EXE.
- Checks EXE, payload hashes, and boot JSON before installer changes files.

Supported game: **Steam 1.0.13 / GoW.exe 1.0.475.7534**. Needs **GoW Script Loader & Gameplay Tweaks 0.22** (`version.dll`) first. Other EXE builds not supported.

Download **CompletionistMap-v1.0.1.zip** from assets below. Close game, extract ZIP, then run `Install.bat`. Use `Uninstall.bat` to restore stock files.
