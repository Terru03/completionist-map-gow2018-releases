# Completionist Map v1.0.6

Released 2026-10-15. **v1.0.6** fixes the fatal Lua trigger exhaustion crash ("ran out of triggers!" in `entityvariablemessaginglibrary.lua`) that occurred when approaching the Cliffs of the Raven in the Lake of Nine or other areas with dense lore markers, while retaining all universal PC build compatibility, chest tracking ancestry validation, native Raven completion authority, and real-time 3D compass clearing with zero regressions.

The exact release package, checksum, and payload provenance are in
[`releases/v1.0.6/`](../../releases/v1.0.6/).

## Root Cause and Solution

- **The Issue:**
  - When players approached the Cliffs of the Raven in the Lake of Nine (`WAD_Cal100_Hub`), the game crashed with an unrecoverable Lua error:
    ```text
    Running VM WAD_Cal100_Hub: Unrecoverable Lua error
    Z:\int8\gameart\scripts\libraries\design\entityvariablemessaginglibrary.lua:216: ran out of triggers!
    [C]: in function 'OnValue'
    libraries\design\entityvariablemessaginglibrary.lua:216: in function 'CreateMonitor'
    libraries\design\entityvariablemessaginglibrary.lua:245: in function 'Initialize'
    libraries\design\entityvariablemessaginglibrary.lua:257: in function <libraries\design\entityvariablemessaginglibrary.lua:150>
    [C]: in function 'call'
    libraries\core\profile.lua:0: in function 'RegisterForVariableUpdate'
    levels\caldera\cal100_hub\cal100_hub.lua:273: in function 'original'
    ```
  - In `GoW.exe` (RVA `0x7814c0`), the game engine allocates a static array of exactly 512 trigger slots (`cmp r9d, 0x200`).
  - In `langcheckruneread.lua`, the observation wrapper previously hooked `OnStart`:
    ```lua
    if type(OnStart) == "function" then OnStart = wrap(OnStart) end
    ```
  - Unlike chest, artefact, and rift modules, `langcheckruneread.lua` does **not** define an `OnStart` function (it defines `OnPreStart` and `OnScriptLoaded`).
  - Because `OnStart` was not local to `langcheckruneread.lua`, `type(OnStart)` resolved to `_G.OnStart`, which belonged to the enclosing level script (`cal100_hub.lua`).
  - As 26 lore rune markers were instantiated in the Caldera hub, each marker wrapped `_G.OnStart`. When dispatched, `cal100_hub.lua`'s `OnStart` re-executed repeatedly, re-registering ~30 entity variable monitors per marker and quickly exhausting the 512 trigger slots.
- **The Fix:**
  - Corrected the lifecycle hook in `langcheckruneread.lua` to wrap `OnPreStart` rather than `OnStart`:
    ```lua
    if type(OnPreStart) == "function" then OnPreStart = wrap(OnPreStart) end
    ```
  - `langcheckruneread.lua`'s own `OnPreStart` is observed cleanly without modifying or polluting `_G.OnStart`.
  - The level script's `OnStart` executes exactly once as intended, keeping trigger usage at ~30 (well within the 512-slot capacity).

## Changes and Improvements

- **Automated Prerequisite Check & Installer (version.dll):**
  - The 1-click installer now automatically detects whether GoW Script Loader (`version.dll`) is present in the game directory.
  - If missing, it automatically installs the bundled `version.dll` from `prerequisites/`, eliminating the issue where loose Lua scripts were ignored and pins failed to disappear from the map.
  - If already present, the existing file is preserved and verified.
- **Trigger Exhaustion Fix:**
  - Fixed fatal crash when entering Caldera Hub / Cliffs of the Raven.
  - Eliminated global `_G.OnStart` pollution from lore rune interact objects.
- **Universal PC Build Compatibility (from v1.0.5):**
  - Fully supports all God of War (2018) PC versions: Steam, Epic Games, GOG, and non-official builds (CODEX, repacks, etc.).
  - Non-blocking dynamic executable detection in installer.
- **Verified Chest Tracking & Native Authority (Zero Regressions):**
  - Retains the exact player-verified v1.0.4/v1.0.5 chest tracking fix in `mapmenu.lua`, verifying inner owner ancestry so opened wooden and red/coffin chests disappear cleanly.
  - Retains Odin's Raven native authority tracking, real-time 3D compass waypoint clearing, and Artefacts/Realm Tears tracking.
- **Multi-Device & Cross-Platform Support:**
  - Full support for Desktop PCs, Laptops, Windows Handhelds (ASUS ROG Ally, ROG Ally X, Lenovo Legion Go, MSI Claw), and Steam Deck / Linux (SteamOS Proton).
  - Includes automated UAC elevation for protected folders (e.g. `C:\Program Files`) and dedicated `Install-SteamDeck.sh` / `Uninstall-SteamDeck.sh` shell scripts with Linux line endings.
- **Native Stability:**
  - Retains Windows 10/11 compatibility layer protections avoiding early ntdll crashes.
  - Statically linked native bridge eliminating external runtime dependencies.
