# Completionist Map v1.0.7

Released 2026-10-21. In **v1.0.7**, I resolved the startup crash where God of War failed to boot on fresh installations with an exception dialog:
```text
An exception has occurred on startup: Unable to load loader_config.toml from the mods directory.
Permission denied or file doesn't exist.
Failed to initialize God of War mod.
```
This release packages `mods/loader_config.toml` directly into the distribution and updates the 1-click Windows installer and Steam Deck script to ensure both `version.dll` and `mods/loader_config.toml` are correctly installed and verified, allowing anyone to install the mod and immediately launch the game without issues.

The exact release package, checksum, and payload provenance are in
[`releases/v1.0.7/`](releases/v1.0.7/).

## Root Cause and Solution

- **The Issue:**
  - In v1.0.6, automatic installation of GoW Script Loader (`version.dll`) was introduced so custom Lua scripts run without requiring a separate manual download.
  - However, `version.dll` (by Nukem9) requires `mods/loader_config.toml` in order to initialize. Without this file, its `DllMain` throws:
    ```text
    Unable to load loader_config.toml from the mods directory. Permission denied or file doesn't exist.
    ```
    and terminates `GoW.exe`.
  - While `version.dll` was included in `prerequisites/`, `mods/loader_config.toml` was omitted from the release package. Clean installations therefore crashed upon boot.
- **The Fix:**
  - Added `mods/loader_config.toml` directly into the package payload and `prerequisites/`.
  - Configured safe, player-optimized default settings (`EnableDebugMenu = false`, `SkipIntroLogos = true`, `LoadScripts = true`, `FileLogLevel = "off"`).
  - Updated `scripts/install.ps1` and `Install-SteamDeck.sh` to automatically install and verify `mods/loader_config.toml` alongside `version.dll`.

## Changes and Improvements

- **Bundled Script Loader Configuration (`mods/loader_config.toml`):**
  - Fixes startup exception crash on clean Steam, Epic, GOG, and unofficial game installations.
  - Automatically installed and verified by `Install.bat` and `Install-SteamDeck.sh`.
- **Zero-Friction 1-Click Install Experience:**
  - Extract the ZIP, double-click `Install.bat`, and launch the game.
  - Automatic game folder detection across Steam libraries, Epic Games, GOG, and custom paths.
  - Automatic Windows UAC Administrator elevation when installed in protected paths (`C:\Program Files (x86)\...`).
  - Automatic backup of original game files to `completionist_backup/`.
  - Automatic registration of marker artwork in `exec/boot-options.json`.
- **Retained All v1.0.6 & Prior Enhancements (Zero Regressions):**
  - Caldera Hub / Cliffs of the Raven trigger exhaustion crash fix (`OnPreStart` observation hook).
  - 551 collectible marker records across 16 custom families.
  - In-map toggle button ([Down Arrow]) to Show / Hide custom markers.
  - Single reticle lock ([Enter] / [E]) to track pins on the 3D compass HUD with live distance meters.
  - Native map category filter integration.
  - Verified chest tracking ancestry validation for opened wooden and red/coffin chests.
  - Odin's Raven native authority tracking and real-time compass waypoint clearing.
  - Steam Deck / Linux Proton support (`WINEDLLOVERRIDES="dxgi,version=n,b" %command%`).
