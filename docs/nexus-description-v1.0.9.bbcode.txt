Odin's Ravens; Nornir Chests, Seals, Bells and Mechanisms; Legendary, Cipher, Wooden and Red/Coffin Chests; Artefacts; Jotnar Shrines; Lore Markers and Scrolls; Realm Tears; Treasure Maps and Dig Sites.

[size=4][b]Windows install / update[/b][/size]
[list=1]
[*]Close God of War. Extract CompletionistMap-v1.0.9.zip fully; do not run from inside ZIP.
[*]Keep existing completionist_backup folder when updating.
[*]Run Install.bat. Select game folder if asked; allow UAC if needed.
[*]Launch game and open map. No save conversion needed.
[/list]
Installer checks payload hashes, backs up affected files, installs missing version.dll and mods/loader_config.toml, then registers artwork. Existing Script Loader and other user options preserved; Lua enabled when needed.

Back up exec/boot-options.json; add ../../patch/pc_le/completionist_v105_family_art to existing patch-texpacks array, keeping other entries. Full steps in README.txt.

After ReShade setup/update replaces dxgi.dll, rerun Install.bat. Shared game archives/map assets may still need mod-specific merged patches; arbitrary mod compatibility not guaranteed.

Steam Deck/Linux scripts retain prior behavior. Back up existing mods before Proton/manual installs; do not overwrite other DLLs or shared config. Startup/driver faults and antivirus review remain separate. No new scanner clearance claimed; see Nexus file scan/review state.

For faults: include game build, Windows/Proton version, NG/NG+ state, exact area, chest type and steps. Keep mods/completionist-map/native/raven-native-bridge.log.
