[size=6][b]Completionist Map v1.1.1[/b][/size]

Every collectible on the in-game World Map and Compass: 551 markers across 16 families, with custom icons, the game's own map filters and completion-aware tracking. Collected items drop off the map. The mod only reads your progress; it never edits your save.

Questions, problems or ideas? Join the Discord: https://discord.gg/URDc8uZmB

[size=4][b]New in v1.1.1[/b][/size]
[list]
[*][b]Realm tears:[/b] an opened tear drops off the map, and only that tear. In v1.1.0 every tear left the map once a Realm Tear Labor tier was completed, even tears not yet opened. Each tear's opened state is now read from the save.
[*][b]MY LIST:[/b] a map filter page showing only the kinds of marker you pick, the mod's families and the game's own shops, gateways, docks, entrances, fights, Valkyries, quests and other locations alike. On MY LIST, [Down Arrow] opens an ON/OFF list.
[*][b]Track up to 5 markers:[/b] [Triangle] Add to Compass keeps the markers already tracked, [Cross] replaces or removes one, and [Triangle] Clear Compass removes them all (a tracked favour stays). At most 2 of one kind at once. Tracked markers come back after a load or restart.
[*][b]Remembered between sessions:[/b] MY LIST, the nearby range and the tracked markers.
[*][b]Raven pins:[/b] [Cross] and the map prompt always act on the marker under the cursor, never on a Raven hovered earlier.
[/list]
Buttons are named as on a PlayStation controller: [Cross] is A on Xbox and [Enter] / [E] on the keyboard; [Triangle] is Y on Xbox and the key the map footer shows.

[*][b]Compass:[/b] 10 side markers instead of 6, a distance on every marker on the bar, and a tracked favour no longer drops off the compass.

[size=4][b]Collectibles and controls[/b][/size]
Odin's Ravens; Nornir Chests, Seals, Bells and Mechanisms; Legendary, Cipher, Wooden and Red/Coffin Chests; Artefacts; Jotnar Shrines; Lore Markers and Scrolls; Realm Tears; Treasure Maps and Dig Sites.

Use the game's map filters or MY LIST to choose what you see. [Down Arrow] on the map hides or shows all Completionist markers (on MY LIST it opens the list); [Up Arrow] changes the nearby range. Hover a pin and press [Cross] to add, replace or remove it as a compass target, and [Triangle] to add another. Valkyries, gateways and shops keep the game's own markers; no duplicates.

[size=4][b]Windows install / update[/b][/size]
[list=1]
[*]Close God of War.
[*]Extract CompletionistMap-v1.1.1.zip into its own folder [b]outside[/b] the game folder (for example Downloads\CompletionistMap-v1.1.1). Do not extract it into the game folder.
[*]Run Install.bat from that folder. Select the game folder if asked; allow the administrator prompt if it appears.
[*]Start the game and open the map. No new save needed.
[/list]
Updating: run the new Install.bat and keep the completionist_backup folder in the game folder; it upgrades v1.1.0 in place. If you ever extracted the mod into the game folder or copied its files in by hand, first use Steam's Verify integrity of game files. The bundled GoW Script Loader is installed if missing; your existing loader settings are kept. ReShade on dxgi.dll keeps working through d3d11.dll.

[size=4][b]Game version[/b][/size]
The 10-marker compass, distances on the bar and one icon per family need game version 1.0.13 (GoW.exe 1.0.475.7534), from any store, DRM-free copies included. dxgi.dll checks the game code and data it uses byte for byte before changing anything; on another version these features stay off and the game keeps its own behaviour. Everything else works on any version.

[size=4][b]Logs and problems[/b][/size]
The main log, mods/loader_log.txt, is on by default and starts empty at every game start, so copy it before starting the game again. The native log is mods/completionist-map/native/raven-native-bridge.log. To turn the main log off, set FileLogLevel = "off" in mods/loader_config.toml. Send the logs, the area and what you did on the Discord: https://discord.gg/URDc8uZmB The README in the ZIP explains every feature and setting.

[size=4][b]Uninstall[/b][/size]
Windows: run Uninstall.bat from any extracted v1.1.0 or later package. It restores the backed-up game files and removes every Completionist file; your saves and settings.json are kept.

[size=4][b]Steam Deck / Linux[/b][/size]
Extract the ZIP in Desktop Mode, then run:
[code]bash Install-SteamDeck.sh "/path/to/GodOfWar"[/code]
Steam Launch Options:
[code]WINEDLLOVERRIDES="dxgi,version=n,b" %command%[/code]
These scripts copy files without the Windows checks and keep the game's 20 m in-world icon distance; they are not tested. Uninstall with bash Uninstall-SteamDeck.sh "/path/to/GodOfWar".

[size=4][b]Known limits[/b][/size]
Up to 5 tracked markers and at most 2 of one kind on the compass. Odin's Ravens fly about and are marked where they perch or start. The Lake of Nine elevator Jotnar shrine is marked where its elevator stops at the top. Mods that change the same game archives or map data may need a merged patch.
