[size=4][b]Windows install / update[/b][/size]
[list=1]
[*]Close God of War. Extract CompletionistMap-v1.0.8.zip fully; do not run from inside ZIP.
[*]Keep existing completionist_backup folder when updating.
[*]Run Install.bat. Select game folder if asked; allow UAC if needed.
[*]Launch game and open map. No save conversion needed.

Installer checks payload hashes, backs up affected files, installs missing version.dll and mods/loader_config.toml, then registers artwork. Existing Script Loader preserved.

Extract ZIP in Desktop Mode, then run:
[code]bash Install-SteamDeck.sh "/path/to/GodOfWar"[/code]
Steam Launch Options:
[code]WINEDLLOVERRIDES="dxgi,version=n,b" %command%[/code]

[size=4][b]Manual / mod managers[/b][/size]
Copy dxgi.dll, exec/ and mods/ beside GoW.exe. Copy prerequisites/version.dll if missing. Keep mods/loader_config.toml with [Lua] LoadScripts = true. Back up exec/boot-options.json; add ../../patch/pc_le/completionist_v105_family_art to existing patch-texpacks array, keeping other entries. Full steps in README.txt.
